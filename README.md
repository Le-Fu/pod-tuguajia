## 一、安装与更新

### 系统要求

- **macOS 10.15+**（提供 Intel x64 安装包，Apple Silicon 通过 Rosetta 2 运行）
- **Windows 10/11（64 位）**（提供 NSIS 安装程序，支持自定义安装路径）
- 磁盘空间 ≥ 2GB（含本地 AI 模型），安装包约 180MB

### 安装步骤

#### macOS

1. 前往 [Releases 页面](https://github.com/Le-Fu/pod-tuguajia/releases/latest) 下载 `POD-ImageVault-x.x.x-mac-x64.dmg`
2. 双击打开 dmg，将 **POD图管家** 拖入「应用程序」文件夹
3. 首次打开：在「应用程序」中**右键点击应用图标 → 选择「打开」** → 弹窗中再点「打开」
   （应用未做苹果开发者签名，直接双击会提示"无法验证开发者"，右键打开一次即可）
4. 首次启动约 3 秒加载本地模型，之后进入主界面

#### Windows

1. 前往 [Releases 页面](https://github.com/Le-Fu/pod-tuguajia/releases/latest) 下载 `POD-ImageVault-x.x.x-win-x64-setup.exe`
2. 双击运行安装程序，可自定义安装目录，默认创建桌面快捷方式「POD图管家」
3. 首次运行若弹出 **Windows SmartScreen「已保护你的电脑」**：点击「更多信息」→「仍要运行」
   （应用未做 Windows 代码签名，仅首次安装需要此操作）
4. 后续可通过桌面快捷方式或开始菜单启动

### 自动更新

应用内置更新检查（启动后自动检查 + 手动触发），macOS 与 Windows 均支持：

- 打开 **设置 → 关于与更新 → 检查更新**；应用启动后也会自动检查（6 小时节流）
- 发现新版本会弹窗展示版本号、更新说明与安装指引，可选择「忽略此版本」或「稍后提醒」
- 点击「前往下载」会用系统浏览器打开**当前平台对应的安装包**（mac → dmg / Windows → exe），
  下载完成后按上方安装步骤覆盖安装
- 更新源为国内加速的阿里云 OSS（主源）+ GitHub Releases（兜底），主源不可用时自动切换
- 更新不会丢失你的图库数据（数据保存在系统用户目录，与应用本体分离）
  - macOS：`~/Library/Application Support/pod-image-vault/`
  - Windows：`%APPDATA%/pod-image-vault/`

## 二、首次配置

首次启动会进入**配置引导页**（图库根目录 → 嵌入模型 → 开始使用），也可随时在「设置」页调整：

1. **设置图库根目录**：选择一个专门存放图库的文件夹（所有图片、缩略图、数据库都在其中，便于备份）
2. **创建店铺与品类**：设置 → 资源分类管理 → 店铺 / 品类
   - 品类隶属于店铺，每个品类可设置**预设尺寸**（变形模块会用到）
   - 店铺码、品类码为 1-3 个大写字母（如店铺 `A`、品类 `T`、店铺 `ABC`），用于自动命名
3. **模型配置**（默认本地模型即可离线使用）：
   - 嵌入模型：默认「本地 CLIP ViT-B/32」，用于向量去重
   - 超分模型 / 去背景模型：默认本地 ONNX，也可配置云端 API（火山 / 阿里）提速

> 💡 macOS / Windows 未签名应用的首次信任引导会在首次启动时展示一次，
> 按图示操作后确认即可（此后不再弹出，详见下方 FAQ）。

## 三、功能模块总览

左侧边栏共 9 个模块（自上而下）；「入库」藏在右下角「+」悬浮按钮里：

| 顺序 | 模块 | 作用 |
|----|------|------|
| 1 | **工作台** | 按卖家工作流组织的任务总入口 |
| 2 | **去重** | 新图之间、新图与图库之间的相似度查重 |
| 3 | **侵权自检** | 与风险库四路比对，上架前自查侵权风险 |
| 4 | **变形** | 批量裁剪/旋转/对齐/换底，导出符合平台尺寸的成品图 |
| 5 | **抠图** | 智能去除图片背景，输出透明底素材 |
| 6 | **超分** | 低清图片放大增强（2/3/4 倍） |
| 7 | **压缩** | 批量把图片压到目标体积以下 |
| 8 | **图库** | 浏览/管理已入库的图片（店铺→品类→标签→图片四级导航） |
| 9 | **标签管理** | 全局标签管理与 AI 打标 |

另有右下角「+」悬浮按钮打开**入库工作台**，把新图片批量归档进图库。

> 💡 典型流程：**入库前去重/侵权自检 → 抠图/变形处理 → 超分/压缩 → 入库归档 → 图库浏览/复用**

## 四、工作台

打开应用首先进入**工作台**：按 POD 卖家的工作流把常用模块分成三段——

1. **素材清理**：去重、侵权自检，先把源头风险清干净
2. **图片加工**：变形、抠图、超分、压缩，把素材处理成可上架的成品图
3. **归档编货号**：入库（右下角「+」）、图库浏览与标签管理

- 每段任务入口点击直达对应模块；有任务进行中时会显示进度，点击可跳回查看
- 全新空图库时提供**三步引导**（设置目录 → 建店铺品类 → 入第一批图），并可一键填入**示例数据**练手
- 不确定名词含义时，可在图库页打开**名词说明**速查

## 五、图库管理

![图库](assets/图库.png)

- **四级层级导航**：店铺 → 品类 → 标签 → 图片，顶部面包屑可跳级切换
- **层级即时过滤**：店铺 / 品类 / 标签列表各自支持关键词即时过滤（匹配名称、代号、备注），
  各层级过滤条件互不影响；创建店铺 / 品类 / 标签通过右侧抽屉面板完成
- **跨层级搜图提示**：搜索图片时顶部 banner 显示检索范围（跨店铺 / 跨品类 / 跨标签），避免误解
- **虚拟滚动网格**：单图库支持上万张图片，滚动流畅
- **图片详情**：点击图片可查看/编辑 产品ID、标题、元素描述、备注 等元信息；
  Windows 上「打开所在文件夹」按钮可直接定位图片文件（macOS 为「在访达中显示」）
- **多选操作**：点击选中，Shift+点击 区间多选，支持批量操作
- **批量搜索**：搜索框支持逗号分隔多个关键词（如 `L_YS_BK_000052,L_YS_BK_000032`），
 命中任一关键词的图片都会返回，便于按编号清单批量找图
- **批量标记不可用**：多选模式下可一键将所选图片标记为不可用（半透明显示、不删文件、可恢复），
  执行前有确认弹窗说明含义
- **备注可追溯**：替换图片 / 补充元信息时，备注只追加不替换，每条写入自动带日期
  （如 `[2026-09-14] 原文件名: xxx.jpg`），旧的商品编号、标题等自动迁移到备注，历史信息不丢失
- **封面托管**：可为店铺、品类设置封面图
- **同步盘点**：可补录磁盘上存在但未登记到数据库的文件
- **以图搜图**：进入某个品类后，点工具栏「上传图片」，选择或拖入一张本地图片，
  即可以图搜图——按视觉相似度（CLIP 向量）在当前店铺+品类范围内检索，结果按相似度
  排序并标注百分比徽章。点「退出搜图」即清空上传图与结果、恢复正常浏览
  （需嵌入模型可用，不可用时会提示去设置页配置）
- **筛选条**：店铺/品类/标签以即时生效的 chips 呈现，实时显示分面计数（零计数置灰）；
  在架状态三态筛选（全部 / 在架 / 已下架）；支持按宽度 / 高度 / 文件大小排序
- **跨店复用**：在图片上点「复用到…」可把它挂到其他店铺/品类，生成**复用位**——
  纯引用不复制文件、不重复占空间、向量不重算；复用位卡片带「复用」角标与复用时间，
  摆位级货号不可改，复用前有预检提示

## 六、一键入库

![入库](assets/入库.png)

把处理好的图片批量归档进图库。

1. **导入图片**：整页拖入文件夹 / 零散图片，或点击虚线框选择文件夹
2. **选择店铺与品类**：入库目标位置
3. **确认去重已完成**：入库前系统会提示先完成去重检查，避免重复图入库
4. **开始入库**：
   - 自动按 `店码_品码_6位序号` 命名（如 `A_T_000001.jpg`，店码/品码支持 1-3 位大写字母），
     序号严格递增、不重号
   - 自动计算哈希（精确去重）+ 生成向量（语义检索）
   - 任务支持崩溃续传，中断后重新进入可继续
5. **入库工作台**：点击右下角「+」悬浮按钮全屏打开，支持整窗拖入；
   最小化后保留草稿、可继续浏览图库，再次打开自动预填上次的店铺/品类

## 七、智能去重

![去重](assets/去重.png)

基于 CLIP ViT-B/32 的 **512 维向量余弦相似度**检索，裁剪、旋转、轻微变色仍能识别为相似。

### 两种去重模式

- **自去重**：检查本批新图**彼此之间**是否重复
- **图库去重**：检查新图与**图库里已有图片**是否重复（命中范围 = 目标店铺全品类 + 其他店铺所选品类）

### 审核方式

- **列表态**：快速浏览所有重复组
- **全屏态**：左侧看新图大图，右侧看相似图网格，逐组审核决策

### 操作与快捷键

| 按键 | 作用 |
|------|------|
| `Enter` | 保留当前新图 |
| `E` | 丢弃当前新图 |
| `←` / `→` | 上一组 / 下一组 |
| `Esc` | 退出全屏 / 关闭大图预览 |

- 相似度配色：**≥92% 红色**（高度重复）、**≥85% 橙色**、其余黄色
- 右侧相似图网格可调整每行张数（1-8），点击卡片查看大图
- **确认并导出**：按审核结果导出图片；也可导出 **CSV 详情表**（含硬拦截/灰区复核/自去重组等分区）

> ⚠️ 去重不会自动删图，所有组都需要人工勾选「保留/丢弃」后再导出。

## 八、侵权自检（风险库）

在入库/上架前自查图案是否撞车：四路比对 + 可选云端复核，**只标记不拦截**，下不下架由你决定。

### 四路比对

| 通道 | 检出什么 |
|------|---------|
| sha256 | 与风险库完全相同的文件（精确命中） |
| pHash | 裁剪/缩放/加码后仍相似的感知哈希 |
| CLIP | 视觉内容高度相似的图案 |
| 文件名关键词 | 文件名命中风险词（如品牌词） |

### 结论与复核

- 命中项按风险等级分级展示，支持全屏逐条复核
- 人工复核三态：**待复核 / 确认风险 / 误报豁免**
- 可选开启**阿里云内容安全云端复核**做二次确认（需在设置中配置，按量计费）

### 风险库导入

- 第三方检测结果 JSON
- Temu 违规下架 JSON
- 图片文件夹（把已知侵权图拖进来作为比对基准）
- 也支持在风险库中手工录入

> 💡 局域网协作模式下，侵权自检仅在主机显示，从机不提供该模块。

## 九、变形（图形转换）

![变形](assets/变形.png)

批量把图案处理成符合平台要求的成品图，基于 Canvas 画板，所见即所得。

### 基本流程

1. **导入图片**：拖入文件夹/图片，或点击选择
2. **选择店铺与品类**：
   - 选了店铺+品类 → 自动加载该品类的**预设尺寸**（只读）
   - 都不选 → 手动输入目标宽高
3. 每张图进入独立**正方形画板**，中间虚线框为裁剪区域（画板边长的 60%）
4. 用工具栏调整，满意后**勾选要导出的画板** → 底部栏导出

### 工具栏功能

- **选择**：全选 / 反选 / 清空（只导出勾选的画板）
- **布局**：Cover（填满裁剪框）/ Contain（完整显示）/ 拉伸填满 / 居中
- **对齐**：3×3 九宫格，9 种对齐方式
- **旋转**：顺时针/逆时针 15° 步进、水平翻转、垂直翻转，也可输入任意角度或鼠标拖拽
- **缩放**：+/- 按钮或直接输入百分比
- **吸附辅助线**：拖动图片、或拖拽四角/四边控制点拉伸时，图片边缘/中心距裁剪框边缘或中线
  6px 内会自动吸附，并显示洋红色辅助线，松手后辅助线消失
- **底色**：可为每张图设置背景色（JPG 默认白底、PNG 默认透明）
- **重置**：单张画板恢复初始状态
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Shift+Z`

### 导出

- 格式：**PNG / JPG**
- 文件名模板支持变量：`{name}`（原文件名）、`{store}`（店铺）、`{category}`（品类）、`{n}`（序号）
- 可选**压缩**：导出时自动压到设定体积以下
- 50 张图同屏不卡：预览用代理图、导出由 Worker 用原图处理
- **二次确认**：点击【处理图片】会先弹层提示已选数量与输出目录，确认后才提交任务
- **导航守卫**：处理过程中切换页面会弹层确认，避免误离开中断任务
- **损坏文件隔离**：遇到损坏或不支持格式的图片时，单文件错误不会中断整个会话，会被收集到"跳过"列表

## 十、超分放大

![超分](assets/超分.png)

把低分辨率图片放大增强，提升清晰度。

- **放大倍数**：2 / 3 / 4 倍
- **图片来源**（三选一）：
  - 从**图库**选图：选择店铺（+品类）后，可按文件名搜索，勾选图片
  - **文件夹导入**：选择整个文件夹
  - **拖拽**：直接拖入零散图片
- **模型**：设置 → 模型配置 → 超分模型
  - 本地 ONNX（推荐，离线、免费）
  - 火山云 / 阿里云图像超分（速度快，需 API Key）
  - 自定义 HTTP 接口
- 后台任务执行，实时反馈进度
- 输出目录会自动记忆，下次默认使用上次位置

> 💡 图库选图超过 200 张时仅显示前 200 张，请用搜索缩小范围。

## 十一、图片压缩

![压缩](assets/压缩.png)

批量把图片体积压到目标阈值以下，满足上传大小限制。

1. 导入图片（拖入文件夹/图片或点击选择）
2. 底部设置**压缩阈值**（默认 5MB）和**文件名模板**
3. 选择输出目录 → 开始压缩

### 压缩规则

- **≤ 阈值**的图片：原样复制，不重复压缩（无损保留）
- **> 阈值**的图片：
  - JPG：质量阶梯压缩（90→50）+ 智能估算边长，mozjpeg 编码
  - PNG：调色板量化，**保留透明通道**；实在压不到阈值会提示改用 JPG
- 结果区展示：压缩/保留/失败数量、节省空间、总压缩率、逐张前后对比
- 独立压缩页超阈值的 JPG 统一输出**白底 JPG**

## 十二、抠图（去背景）

![抠图](assets/抠图.png)

智能去除图片背景，输出透明底素材，方便后续换底、排版。

- **图片来源**：图库筛选 / 文件夹 / 拖拽，三种方式均可批量
- **本地 U2Net 模型**批量抠图，离线可用（也可在 设置 → 模型配置 → 去背景模型 中切换云端接口）
- 输出**透明 PNG**，可选**纯色背景填充**
- 结果区支持**单张重调参**：阈值 / 羽化 / 背景色，并提供前后对比预览
- 处理后可结合「变形」模块换底、排版后导出成品图

## 十三、标签管理

标签与店铺/品类分组解耦，**全局平铺、一处创建、全局可用**。

- **多对多**：一张图片可挂任意多个标签，一个标签可覆盖多张图片
- **手动打标**：图库多选图片后批量打标，详情页可单个增删
- **AI 打标**：基于 CLIP 文本塔零样本分类，本地离线运行，按图片内容自动推荐标签，一键采纳
- **筛选联动**：图库筛选条可按标签过滤，与店铺/品类组合圈图

## 十五、常见问题 FAQ

**Q：macOS 打开提示"无法验证开发者 / 已损坏"？**
A：应用未做苹果开发者签名（v0.2.3 起已做 ad-hoc 签名，一般不会再提示"已损坏"）。在「应用程序」中**右键点图标 → 打开 → 再点打开**即可；若仍提示损坏，终端执行 `xattr -cr /Applications/POD\ ImageVault.app` 后重试。

**Q：Windows 安装/启动时蓝色提示"已保护你的电脑"？**
A：应用未做代码签名，SmartScreen 会拦截首次运行。点击弹窗中的「更多信息」→「仍要运行」即可，仅首次需要；如安全软件进一步提示，选择"允许/信任"。

**Q：升级后我的图库还在吗？**
A：在。数据存于系统用户目录（macOS：`~/Library/Application Support/pod-image-vault/`；Windows：`%APPDATA%/pod-image-vault/`），更新应用不影响数据。

**Q：去重/超分/抠图必须联网吗？**
A：不必。默认使用本地 ONNX 模型，完全离线；配置云端 API 仅为提速可选。

**Q：入库时提示"请先完成去重"？**
A：这是防重复保护。请先到「去重」模块检查本批图片，确认无重复后再入库。

**Q：变形导出的图被裁掉了？**
A：裁剪以中间虚线框为准，框外内容不导出。可用 Contain 布局或缩放/对齐调整图案位置，确保主体在框内。

**Q：从机提示"与主机失去连接"怎么办？**
A：从机每 15 秒做一次心跳检测，连续 3 次失败会自动切换到"失联"状态（顶部 banner 提示并显示失败原因），此时数据仍可只读浏览，写操作会被拦截。等主机恢复后会自动重连并刷新数据，无需手动操作；也可点 banner 上的「立即重连」马上尝试，或去「设置 → 协作与连接」点【断开连接】切回本机模式。

**Q：升级后从机连不上主机，提示版本不兼容？**
A：v0.3.0 起局域网协作的快照格式升级，主机与从机必须**同时升级到相同版本**后重新连接，旧版本混连会被拒绝并提示。

**Q：PNG 压缩后还是很大？**
A：PNG 是无损格式，复杂图案压缩率有限。如无需透明背景，导出时选 JPG 可显著减小体积。

**Q：多台电脑能共用一个图库吗？**
A：可以。设置 → 协作与连接，一台作为主机，其余设备在同一局域网内连接即可（从机自动发现主机）。

**Q：遇到 Bug 怎么办？**
A：到 [Issues](https://github.com/Le-Fu/pod-tuguajia/issues) 反馈，并可在 设置 → 日志管理 导出日志附上，便于定位。
