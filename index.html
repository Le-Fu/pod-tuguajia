POD图管家

专为 Temu POD 电商从业者打造的一站式图案图库管理工具。向量去重、图形转换、批量入库，全流程本地离线运行。

立即下载 GitHub 使用手册

七大功能模块

模块独立、零耦合，按「去重 → 处理 → 入库 → 浏览」的工作流排布。📖 查看《用户使用手册》→

🗂️

智能图库管理

店铺 → 品类 → 标签 → 图片四级层级导航，面包屑跳级切换。支持封面托管、元信息编辑、批量操作，还能上传一张图按视觉相似度搜图。

虚拟滚动 以图搜图 封面托管 同步盘点
📥

一键入库归档

自动命名、哈希去重、向量入库，命名可逆解析。序号严格单向递增，事务保证原子性。

自动命名 向量嵌入 崩溃续传
🔍

向量智能去重

基于 CLIP ViT-B/32 的 512 维余弦相似度检索，裁剪/旋转/变色仍能识别。硬拦截 + 灰区人工审核。

本地 ONNX 规则引擎 自去重
🎨

批量图形转换（变形）

Canvas 画板批量裁剪/旋转/对齐/缩放/换底，选店铺品类自动套用预设尺寸；代理图预览 + Worker 原图导出，50 张同屏不卡。

画板所见即所得 吸附辅助线 预设尺寸 PNG/JPG 导出
🔎

图片超分放大

低清图案 2/3/4 倍放大增强。可插拔模型：本地 ONNX 离线免费，或火山/阿里云接口提速；图库选图与外部拖拽均可。

2/3/4 倍 本地/云端可选 后台任务
🗜️

批量图片压缩

自动把超过目标体积的图片压到阈值以下，未超限的原样保留不重复压缩；mozjpeg 质量阶梯 + PNG 透明保真，逐张前后对比。

阈值自适应 PNG 透明保真 压缩率统计
✂️

智能抠图（去背景）

本地 U2Net 模型批量抠图，输出透明 PNG，可选纯色背景填充。结果区支持单张重调阈值/羽化/背景色，前后对比预览。

本地 U2Net 透明 PNG 单张精修

💡 移动到截图左侧的模块栏上会高亮，点击即可像切换页面一样预览对应模块

模块化四层架构

主进程分层解耦 + 渲染进程模块注册表，新增功能只需注册不改已有。
